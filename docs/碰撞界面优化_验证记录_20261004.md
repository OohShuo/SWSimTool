# 碰撞界面优化验证记录（2026-10-04）

本轮只使用工作区中新建的装配和零件；未打开、读取或修改用户现有 SW 工程。

## 修改

- 碰撞配置入口读取 link 树和已有坐标系，移除完整 robot 构建、质量惯量计算和关节推断。
- 在关闭回调结束后通过创建页面的 UI 线程队列切换页面。确认/取消返回原 URDF 页，重新绑定树窗口，保留选中节点、展开状态与零件归属；避免关闭和树句柄重建事件清空原配置。
- 几何体/碰撞对标签、单滚动区、下拉框滚轮不切换值、按形状和标定方式显示字段；尺寸和位姿分别输入。
- 角点坐标系 box 支持每轴正负延伸；端面圆心坐标系 cylinder 支持 X/Y/Z 拉伸轴及正负方向。
- 直线边可驱动适用的长度字段，引用随装配 Attribute 和 `.sim.json` 保存，CAD 变化时重新求值。
- 增量临时体预览：无更改/名称不更新、位姿复用临时体、尺寸只重建目标、选中高亮不重建。首次进入和 CAD 更新时重新解析参考。
- 原始 URDF/STL 输出逻辑保持不变。

## 验证结果

SolidWorks Premium 2025 SP1.2、.NET Framework 4.8 x64、本地 Python 3.12 与 MuJoCo 3.14.0。

- x64 编译通过；后端 30 项回归通过（含已安装的三种减面后端）。
- 新建装配实机验证：四种临时体显示不改变质量；box 中心和全尺寸与 MJCF 一致。
- 增量预览计数验证通过：不变/名称修改无重绘无重建；位姿变化复用体；尺寸变化只重建一个；高亮变化复用体。
- 角点 box 中心计算、端面 cylinder 六种轴/方向、选择真实直线边计算长度通过。
- Attribute 保存、装配重新打开、持久点/坐标系/边引用重新解析通过。
- 原生左侧页面：进入无需 robot 导出准备；单滚动区；box 下拉框滚轮滚动页面且值不变；碰撞对标签及添加 link 对可用。
- 取消和确认返回均通过运行时断言：同一选中 link，零件归属数量保持 1，树恢复显示，预览清理。
- 实际 CAD 导出的包转换通过：原 URDF/STL/JSON 哈希不变，低面数 STL 副本字节一致，碰撞位姿一致，内部排除生效，1000 步仿真位置/速度有限。

脚本：`New-CollisionFixture.ps1`、`Test-CollisionCAD.ps1`、`Test-CollisionPageFlow.ps1`、`Test-CollisionPackage.py`。关闭测试实例的 `Close-CollisionFixture.ps1` 检查进程标识及全部文档路径，遇到非测试工程拒绝关闭。
