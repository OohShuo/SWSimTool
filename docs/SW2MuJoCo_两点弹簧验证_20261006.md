# SW2MuJoCo 2.7 两 site 弹簧实现与验证

按要求先提交既有工作：ce4f95d（两 site 恒力）、526c8b5（2.6 文档与打包）。本轮弹簧更改留在工作区，未自动提交或推送。

## 实现

仿真配置的两点作用力新增 spring；选择两个已有 site，link 自动推断。刚度 N/m、阻尼 N·s/m 默认 0；自然长度可取初始距离或自定义 m。字段按类型和长度模式显示，模式切换保留输入和无关控件。原 pull/push 仍可使用。

后端使用被动 spatial tendon，实现双向线性弹簧与相对长度速度阻尼，不生成 actuator，不依赖运行时回调。取初始距离在 qpos0 姿态求值并显式写入 springlength，避免关节弹簧参考姿态影响。稳定 site ID、改名同步、配置保存和可选侧文件沿用原实现。

## 验证

- Release x64 编译通过，DLL 2.7.0.0；保留既有分析警告。
- Python / MuJoCo 3.14.0：85 项后端测试通过。
- WinForms / 模拟 CAD：112 项界面检查通过。
- 两自由刚体验证拉伸、压缩、自然长度下的胡克力，等大反向作用；验证纯阻尼抵抗正负相对速度。
- 有阻尼弹簧持续步进状态有限；启用弹簧不增加控制槽或等式约束。
- 初始距离模式在非零 joint ref 下零初始弹性力，独立加载导出 XML 自然长度一致。
- 负值、非有限值、无效模式和初始重合拒绝，失败保留原输出；关闭条目不导出，非当前模式字段不影响有效配置。
- spring 显示刚度与阻尼并隐藏恒力；自定义模式单独显示自然长度。类型切回恢复恒力值，序列化保留弹簧参数及稳定引用。
- 230×270 窄面板可滚动到底部；截图 build/site-spring-bottom.png 已检查。
- 未打开、使用或修改任何用户现有 SW 工程。真实 SW 宿主内拾取与原生侧栏尚未现场验证。

安装包包含更新的 site_forces.py。日志：build/site-spring-build.log、site-spring-ui.log、site-spring-backend.log、site-spring-setup.log。

## 使用范围

双向线性弹簧，不是仅拉伸绳索或单向压簧。默认刚度与阻尼均为零，实际值由用户填写；运行中避免端点重合。CAD 仅预览连线。普通 URDF/STL、网格减面、缓存、原恒力和其余导出功能保留。
