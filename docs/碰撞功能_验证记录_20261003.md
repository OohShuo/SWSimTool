# 碰撞配置验证记录

验证只使用插件工作目录 `build/collision-validation-20261003-210028` 中本次新建的 `isolated_fixture.SLDASM` 和两个测试零件；没有打开、使用或修改用户现有 SW 工程。

## 环境

- SolidWorks 2025 SP1.2，x64。
- 本地 Python：`D:\Softwaves\python\python.exe`；MuJoCo 3.14.0。
- 后端回归使用本机 PyMeshLab、fast-simplification 和 Blender。

## 已通过

1. C# 插件构建成功；坐标轴正交性、右手系、RPY 重建、不同 SW Configuration 的 JSON 记录隔离、非法尺寸拒绝通过。
2. 后端共 30 项回归通过。新增覆盖四种代理的尺寸转换、默认内部排除、显式父子接触、多代理接触组合、外部地面接触、原质量惯量保留、旧 JSON 兼容及错误配置不覆盖已有输出。
3. SW API 创建并显示长方体、球、圆柱、胶囊临时预览；显示期间装配质量不变。左侧编辑页面实际打开，修改长方体尺寸可更新预览。
4. SW 实机拾取草图点和零件坐标系；两点球半径、两点圆柱长度、坐标系长方体和矩形面加厚均成功解析。持久引用及八个几何体保存到装配内 Attribute 节点后，关闭并重新打开测试装配，全部可读回并解析。
5. 在同一个已计算的 URDF 模型上，配置前后写出的 URDF 逐字节一致。重新打开 SW 后再计算惯量时可能出现约 1e-18 的原生浮点尾差，不把这种重新计算尾差当成配置改变 URDF。
6. 实际导出测试装配的 URDF、STL 和 `.sim.json`，再转换为保留 URDF 和 STL 副本的 MJCF 文件包。
7. 端到端检查原始 URDF、STL、JSON 哈希不变；未超限 STL 的副本逐字节相同；MJCF 代理位置与 link 局部配置一致；默认内部接触数为零；连续运行 1000 个仿真步，状态均为有限数。

## 验证边界

目前实机参考拾取覆盖草图点、零件坐标系及矩形平面。球面、圆柱面等其余解析方式已实现，但尚未逐项完成 SW 鼠标拾取验证。测试装配规模很小，不能据此证明大型工程上的编辑性能。

最终构建已验证：长方体预览的八个顶点经反变换后，中心和三个方向的边界与 MJCF 尺寸一致。左侧尺寸从 `40 30 20` 改为 `20 15 10` 后，预览立即缩小；取消关闭后临时实体全部消失。进入编辑器前清除导出残留的组件选择，避免原零件被选择高亮染色。

当前 SW 2025 实机的预览仍呈现不透明彩色实体，临时面的透明材质设置未得到可见透明效果。此项不影响几何位置、尺寸、保存或 MJCF 的透明代理显示，不能宣称 SW 半透明预览已完成。安装后的菜单/工具栏升级入口尚未做实机点击验证；左侧编辑器本身已在 SW 中运行验证。
