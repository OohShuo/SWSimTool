# SW2MuJoCo 2.2 关节配置验证

新增独立关节配置页面、单自由度关节覆盖、位置轴向持久引用、固定 / 浮动根基座和执行器页的关节合计驱动力限幅。原 URDF / STL 输出不修改。

本机 Python / MuJoCo 3.14.0 后端 50 项测试通过：包含原转换、碰撞、减面与求解预设回归，新增关节物理参数、子 link 相对位置轴向、限位求解参数、hinge / slide 切换、浮动 / 固定基座、gear 之后的多执行器合计限幅、非法设置保留原输出、显式零与继承区别以及不同 joint 独立性。浮动根缺少惯量时明确失败，不猜测参数。

WinForms 模拟 CAD 回归 47 项检查通过，覆盖条件字段、独立关节草稿、输入校验、不同 joint 切换、较硬限位默认值、弹簧初值 0、JSON 往返和同 joint 多 actuator 共用一个限幅条目。测试日志位于 build/joint-settings-ui-tests.log。

x64 插件编译与完整 Setup 打包通过。没有打开或修改已有 SW 工程。本轮未进行原生 SolidWorks 页面点击和 CAD 持久参考拾取验证；后端测试与模拟界面验证不等同于真实机械系统动力学验证。

## 2.2.1 界面修复

普通物理参数及 XYZ 去掉覆盖勾选框，空值继承、显式零覆盖。关节页面使用直接滚动容器，条件项原位显隐，高级求解和全局求解开关保留滚动位置。新增回归检查空值/零、部分 XYZ 校验、230 px 窄侧栏滚动、底部 ref 可达、开关前后控件身份及滚动位置。仍未操作用户现有 SolidWorks 工程。

修正版 WinForms 回归 58 项、本地后端 50 项全部通过；x64 编译和 Setup 2.2.1.0 打包通过。窄侧栏无横向滚动，底部字段可达。
