# MuJoCo 碰撞配置

## 配置入口

先在 SolidWorks 装配中配置并保存 URDF link 树。然后使用 **MuJoCo 工具栏 → 碰撞配置**，或 URDF 左侧页面中的 **碰撞几何体 / 碰撞对…**。编辑器显示在左侧 PropertyManager，支持直接在模型中拾取参考对象。

进入碰撞配置只读取 link 树及已有坐标系，不计算质量、惯量、材料，也不自动推断关节。各 link 需先指定已有的坐标系。由 URDF 页面进入时，确认或取消均返回原 URDF 配置页，保留选中的 link 和树展开状态。由独立工具栏进入时，退出返回模型。

左侧分为 **几何体**、**碰撞对** 两个标签。字段较多时只滚动标签内容；鼠标停在下拉框上滚动不会切换选项。需要改变选项时点击下拉列表或使用键盘。

碰撞配置写入装配特征树的 **MuJoCo Simulation Configuration (v1)** 节点。它采用与 URDF 配置节点同类的 SW Attribute 存储；重新编辑使用上述命令，不依赖双击 Attribute 节点。点击保存或左侧绿色勾后，需要正常保存 `.sldasm`，才能将修改写到磁盘。取消不会保存未确认的编辑；已经点击“保存到装配配置节点”的内容不会因之后取消而撤销。

配置按 SolidWorks Configuration 分开保存。旧 `.sldasm.sw2urdf.json` 仅作为当前 Configuration 的迁移来源，装配内记录优先；不覆盖旧 JSON。迁移后保存装配，配置随装配文件保留。

## 几何体与参考选择

每个 link 支持 **原网格 / 简单几何体 / 无碰撞** 三种模式。简单几何体模式至少需要一个几何体，可组合多个几何体保留支架的孔洞和开口。添加几何体时自动选择简单几何体模式。

| 类型 | 定义方式 |
|---|---|
| 长方体 | 手动；中心坐标系＋尺寸；角点坐标系＋尺寸；中心点＋link方向；中心点＋方向坐标系；矩形面＋厚度 |
| 球 | 手动；坐标系原点＋半径；中心点＋半径；球心＋球面一点；球面 |
| 圆柱 | 手动；中心坐标系＋半径和高度；端面圆心坐标系＋拉伸轴；中心点＋方向坐标系；两个端面中心点＋半径；圆柱面＋两个轴向范围点 |
| 胶囊 | 手动；坐标系＋半径和圆柱段长度；中心点＋方向坐标系；两个端部球心＋半径；坐标系＋半径和总长度 |

只显示当前形状和标定方式需要的尺寸及拾取按钮。先点击具有明确名称的拾取按钮，再选择模型对象，按显示顺序填写。支持参考点、顶点、草图点、坐标系和几何面。两点方式要求点不重合；方向参考必须为坐标系。圆柱面方式依次拾取圆柱面、范围点1、范围点2，范围点投影到圆柱轴线。矩形面必须是四条直边组成的矩形，无孔、圆角，厚度可向法向、反法向或两侧对称延伸。

界面尺寸、位置用 mm，角度用度。所有形状最终保存相对所属 link 的位姿，JSON 使用 m、rad。坐标系定义的轴体沿 Z 轴，原点位于中心。长方体输入完整长宽高，圆柱输入完整长度；胶囊圆柱段长度等于两个端部球心的距离，总长度＝圆柱段长度＋2×半径。圆柱段长度必须大于0，完全退化的胶囊应使用球。

长、宽、高等数值分别输入。适用的长度字段旁可点 **拾取直边**，再选一条直线边，自动计算其长度。直边引用随配置保存，CAD 变化或重新导出时重新求值；点击 **改为手动** 可解除引用并保留当前长度。半径使用手动输入或球面/圆柱面等标定方式，不能把边长直接作为半径。

**角点 box**：坐标系原点放在一个角点，长宽高沿该坐标系 X/Y/Z 轴定义，三个轴分别选正或负方向。系统将每轴半尺寸偏移换算到几何中心；无需手动将原点移到中心。

**端面圆心 cylinder**：坐标系原点放在一个端面的圆心，选择该坐标系的 X/Y/Z 作为拉伸轴，再选择正或负方向，分别输入半径和完整高度。系统沿所选方向移动半高得到圆柱中心，并将导出圆柱的 Z 轴对齐拉伸方向。

参考偏移和旋转应用在参考几何体的局部坐标系中。球仅使用位置，方向不影响形状。引用与上次有效数值一并保留，引用失效时报错，必须重新拾取后保存或导出。

## 实时预览

修改参数后约180 ms更新临时预览；当前几何体高亮，其余淡色。可取消“显示碰撞几何体”。输入或参考不完整时显示原因，并保留上一次有效几何预览；无有效参考的新几何体不能保存。

无更改时不重建、不重绘；名称和碰撞对修改不更新几何。位姿变化复用原临时体，尺寸或形状变化只重建对应几何体，增删只影响相应对象。CAD 更新后重新解析引用，实际几何没有变化时不重建。切换 SW Configuration 后需关闭并重新进入编辑器。

当前 SW 2025 实机预览为彩色实体；透明材质尚未产生可见透明效果。观察遮挡区域时可旋转视角或暂时关闭预览。MJCF 中的代理几何体则设置透明颜色。

预览使用临时 Body，不创建实体特征、不加入零部件。关闭编辑器时清除临时显示，不参与质量、惯量和 STL 导出。胶囊预览以圆柱及两端球面组合显示。

## 碰撞规则与 MJCF

新导出的 `.sim.json` 默认设置 `disable_internal=true`，为未允许的内部 link 对生成 `contact/exclude`。打开左侧 **碰撞对** 标签，指定两个不同 link，点击 **允许此对**，再保存；后端将两个 link 的碰撞几何体组合展开为 `contact/pair`，包括通常被父子过滤的组合。无碰撞模式的 link 不能加入允许列表。

该设置仅关闭模型内部碰撞；机器人与后续添加的地面或外部物体仍由各自碰撞属性决定。普通网格模式仍使用 MuJoCo 的凸碰撞表示，减面不能解决凹面凸包问题。

简单几何体模式：原网格保留外观，`contype=conaffinity=0`，新增 `geom` 负责碰撞，位于可视化 group 3。查看生成模型的碰撞几何体时可启用 group 3、隐藏其他显示组。保留原模型的质量、质心、惯量；几何体不添加质量。建议明确区分碰撞代理与真实几何细节。

输出流程仍是先处理 STL 副本，再读取保留的 URDF，最后将碰撞配置应用到 MJCF，重新编译后保存。原 URDF 与 STL 不修改。没有 `collision` 字段的旧 `.sim.json` 沿用原行为；在新版 SW 中重新导出时，会得到默认排除内部碰撞的配置。

## 验证范围

后端回归覆盖四种几何体的尺寸转换、内部排除、父子显式接触、多代理接触组合、与地面的接触、原惯量保留、旧JSON兼容及错误配置不覆盖已有输出。

SW 实机验证仅使用新建隔离装配；不得用于用户已有工程。
