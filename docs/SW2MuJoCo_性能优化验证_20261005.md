# SW2MuJoCo 2.5 性能优化与验证（2026-10-05）

审查材料基于 2.3；本轮在未提交的 2.4 动态 UI 和稳定 site ID 更改上继续实现。

## 已实现

1. STL 内容缓存：SHA256 + 面数预算 + 后端包版本（Blender 使用可执行文件路径、大小、修改时间指纹）+ 减面脚本内容哈希。缓存验证哈希、STL 结构、面数，坏缓存重算，写缓存失败不阻止导出，约 512 MiB 淘汰，仅清理本缓存生成的条目。
2. 旧输出包暂存优先硬链接，写入前解除链接，保留原子目录替换与失败回滚；同卷不再整包复制网格字节。文件比较改为大小 + 流式哈希，不把两个 STL 整体读入内存。重复 mesh 路径只读一次。
3. 二进制 STL 在现有字节中读取面数；ASCII 解析结果和超限网格三角形数据传给减面器复用，避免重复读取和解析。仍校验序列化减面结果。
4. CAD 候选源和碰撞几何求值缓存。配置、模型更新戳、更改几何输入或手动刷新时失效。当前左侧界面不依赖 Sources() 全装配扫描；候选源缓存主要改善旧窗口。原有 link 树变换缓存保留。
5. 仿真/关节/碰撞预览依据几何输入跳过无关更新，物理参数变化不触发无关几何重建；实时预览继续工作。新增“刷新 CAD 参考”，不改变或自动重建用户装配。
6. 存储缓存已校验 Attribute 原文，减少重复 URDF 树校验；读取仍反序列化独立草稿，避免草稿污染缓存。保存只序列化一次，保留完整对象校验、逐字回读和失败回滚；清理旧节点时一次收集候选 Attribute。
7. 可选分段耗时记录，默认关闭；不增加预览周期 Diagnostics。环境变量 SW2MUJOCO_PROFILE=1 启用，Python 使用 perf_counter，C# 使用 Stopwatch/Trace。

## 实测

合成 131072 面 STL，fast-simplification，预算 8192 面：首次导出 0.483 s；仅改变求解步长后再次导出 0.084 s，命中减面缓存。源 URDF/STL 逐字不变。

这是同一实现的冷缓存与热缓存比较，包含依赖首次使用开销，不是旧版与新版对比，也不是实际 SW 装配的测量。实际收益取决于网格、后端、磁盘和 CAD 开销。复现：D:/Softwaves/python/python.exe scripts/Benchmark-MeshExport.py。详细阶段记录位于 build/performance-benchmark.json。
