# 碰撞配置 link 切换修复

问题：切换所属 link 或几何体之前，界面强制解析当前几何体的 CAD 参考。参考缺失或失效时，校验异常中断刷新，而下拉框或列表的选中项已经改变，造成显示不一致。

修复：浏览其他 link、选择其他几何体和添加几何体时，允许保留未完成的参考配置及已输入的有效尺寸。解析使用独立副本，失败时保留最后有效位姿。无效数字仍阻止切换，并恢复对应选中项。实时预览和保存仍使用严格参考校验。

验证：编译通过；`scripts/Test-CollisionNavigation.ps1` 对实际 WinForms 编辑器执行 11 项回归检查，全部通过。涵盖缺参考时切换几何体、输入尺寸保留、最后有效位姿保留、切换 link 后列表和属性同步、空 link 清空旧内容、切回 link、无效数字恢复 link 与几何体选中项、严格解析拒绝缺参考、添加几何体和保存前不修改项目。

本次使用 Moq 模拟 SolidWorks 接口，没有连接 SolidWorks，也没有读取或修改用户现有 CAD 工程。此记录不代表在真实 CAD 界面进行了本次修复的验证。

安装：关闭 SolidWorks 后运行 `SW2URDF_SW2025_CollisionNavigation_x64_Setup.exe` 升级。原始 URDF/STL 导出路径未改动。
