## 界面发现与修复

1. PropertyManager 新配置按钮没有显示：补充与原导出按钮相同的 Width=200，并保留控件引用。解锁后已确认显示，选择 arm 后点击可打开并恢复配置。

独立 COM PropertyManager 宿主的 Preview and Export 回调发生 MTA/STA 线程异常，不能作为原生插件点击失败的证据。使用 STA 宿主直接打开生产 AssemblyExportForm，预览按钮成功选择桌面中文目录的 CAD URDF，生成 MJCF，打开 Viewer 显示两个网格，正常退出并生成 UTF-8 中文日志。随后发现导出 MJCF 按钮与原有 Cancel 重叠，已增加工具栏左侧留白。重新编译后的候选窗口已确认 Cancel、导出 MJCF、MuJoCo 预览、Next 均可见且不重叠。

## 桌面路径补测

复制到桌面后发现 MuJoCo Windows 原生网格读取不能打开中文路径。修复为 Python 读取字节、内存 VFS 编译，并生成相对路径的 sw2urdf_assets_* 网格副本。中文桌面目录中的转换、重新加载和 1000 步仿真检查已通过。初始 URDF 与原网格不改写。此路径修复后的 Viewer 界面已通过生产预览按钮复测。实现参照 MuJoCo 官方 Python 文档的 Assets/VFS 接口：https://mujoco.readthedocs.io/en/latest/python.html#assets 。
