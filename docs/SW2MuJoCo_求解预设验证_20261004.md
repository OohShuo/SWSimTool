# SW2MuJoCo 2.1 求解预设验证

本轮新增可选刚性机器人预设、connect / weld 局部覆盖、允许碰撞 link 对局部覆盖。预览已按要求取消周期性诊断输出。旧配置缺少 solver 字段时保持原行为，普通 URDF 与 STL 输出不改变。

验证环境为本地 Python / MuJoCo 3.14.0、Visual Studio x64 构建和 Inno Setup。没有操作已有 SW 工程。

- 后端 40 项测试通过，包含三个减面后端和原导出回归。
- 新求解测试确认 Newton / elliptic / 1 ms 及默认约束参数编译生效；全局关闭保持旧参数；局部覆盖优先；显式 contact pair 的 solref / solimp / margin 生效；未覆盖 pair 继承默认值；非法数值与范围拒绝。
- 诊断测试确认 connect site 间距、球与平面实际穿透距离、状态有限性；预览无日志输出且不修改控制回调；模拟 viewer 内真实 mj_step 执行通过。
- 模拟 CAD 的 WinForms 回归 25 项通过，覆盖按 link 编辑、条件字段、求解预设、配置序列化、碰撞对 margin 草稿隔离、无效数字阻止切换、取消局部覆盖恢复继承。
- 插件 x64 构建与 2.1 完整 Setup 打包通过，solver.py 包含在安装内容中。

本轮未做原生 SolidWorks 页面和真实机器人动力学桌面验证。测试只验证参数导出、界面逻辑和有限的数值例子，不能保证特定闭链机器人在所有驱动与接触条件下稳定。预览不输出周期性诊断日志。
