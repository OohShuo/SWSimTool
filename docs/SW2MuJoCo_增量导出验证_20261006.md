# SW2MuJoCo 2.8 增量导出设计与验证

既有 2.7 已按要求提交：706a0e2（弹簧功能）、a60c432（文档与打包）。本轮重构留在工作区，未自动提交或推送。

## 已实现

- CadRevision / CadReferenceSnapshot：统一文档、Configuration、会话变化与手动刷新；按需解析纯数据，参考目录不持有复杂 COM 对象。点/坐标系、link 坐标、轴向、边长和简单碰撞体结果复用。
- SimulationSession / ExportFingerprint / ExportPlan：应用配置时记录 Dirty；规范化内容哈希与源数据验证决定实际复用，保留首次全量路径。
- ProjectSourceCache：复用已验证 URDF/STL 及导出 link 的纯数值坐标；最新配置重新生成侧文件。只改变 site/简单碰撞体时重新解析对应配置，不要求重新导出 STL。
- Python PreparedInputs / ProcessedMesh：源资源内容、处理设置、后端和生成器版本分离指纹；复用已处理 STL 和无仿真覆盖的基础模型。单个新源内容只准备对应资产，重复内容可共享。
- RobotModel：纯数据基础模型适配层，每次生成全新模板，重新应用完整配置，不 patch 上次 XML。
- 每次生成完整 MJCF，最终编译验证一次；弹簧初始距离按实际 qpos0 求值并写数值。校验阶段之后核对源文件未发生变化，再整包发布；失败保留旧产物。
- 缓存不进入最终包；哈希、二进制结构/面数、版本及配置校验；缓存缺失、损坏、关闭及写入失败均可回退。
- 导出 ID、调用计数、阶段耗时，以及无 SW 访问的合成 benchmark 脚本。

## 机器验收

Given：已存在经过验证的测试源数据；CAD、URDF 树、网格设置不变。
When：timestep 从 0.001 改为 0.002，再次导出。
Then：模拟工程 CAD 几何查询数=0，STL 导出数=0，源数据构建数=0；后端 mesh_prepare=0、mesh_simplification=0、base_generation=0、mjcf_generation=1、mujoco_validation=1，导出成功。
And：清除隔离缓存后完整导出，与增量模型的关键结构/物理参数一致，并额外比较规范化 XML。

C# 验收使用 Mock SolidWorks 与合成源文件播种，未执行真实 SW 的首次 CAD/STL 导出。Python 验收实际使用本地 MuJoCo 3.14.0 编译和 STL 减面，因此不能把这些计数/耗时称为真实 SW 装配端到端测量。

## 保守边界

当前每次工程导出仍检查组件等轻量元数据，并读取文件哈希；零几何查询不等同于零 COM 或零 I/O。无法证明 CAD 未变时完整重导，尚未按受影响 link 单独重导 STL。跨文档重新打开不信任以前会话的 CAD stamp，先完整重建工程源；内容相同的 Python 资源仍可复用。

RobotModel 为渐进适配层，仍以 URDF 导入建立基础模型，尚未完成直接 MJCF 写出。现有服务内部分纯数据缓存继续作为兼容层，不继续独立定义 CAD 版本。未引入常驻 worker，未改 UI 布局。普通 URDF/STL 与最终 XML+meshes 产物约定保留。
