# SW2MuJoCo 2.6 两点恒力实现与验证

先提交既有 2.4/2.5 更改：21a460f（功能与性能）、119851f（说明与打包）。新功能实现留在工作区，未自动提交或推送。

## 实现

仿真配置新增“两点作用力”标签，独立条目包含名称、启用、pull/push、两端已有 site、非负力值 N。默认开启、pull、0 N，不猜测力大小。端点自动推断 link，无所属 link 选择或拾取入口。point/frame 都可，复用稳定 site ID 和重命名同步；序列化写入统一节点、可选 sim.json 和后端配置。

MJCF 为 spatial tendon + 固定偏置 general actuator，gain=0、gear=1，pull 使用 -F、push 使用 +F。长度/速度偏置项、被动 stiffness/damping/frictionloss 为 0，没有新距离约束，不依赖 Python 控制回调。初始重合的非零启用条目在发布前拒绝，原输出保持不变。

选中非零启用条目提供 CAD 连线示意，保留缓存及去抖，不进行物理仿真。解决动态标签嵌套 Panel 对换行文字的高度裁剪，改用直接自动高度表格；类型和开关保留原输入控件与滚动位置。

## 验证

- Release x64 编译通过，DLL 2.6.0.0，保留既有分析警告。
- 本地 Python / MuJoCo 3.14.0：78 项后端测试通过。
- 独立 WinForms / 模拟 CAD：104 项检查通过。
- 拉力/推力在多个姿态下，广义力与两个 site 的位置 Jacobian 转置乘力的结果一致；ctrl 设为 12345 也不改变恒力。
- 两个自由刚体各受 10 N 等大反向力，偏心 0.1 m 产生 1 N·m 反向力矩；持续步进中力大小恒定，状态有限。
- 覆盖启用/关闭、零力、负值/非有限值、错误类型、重复/不存在/同 link 的 site、site 改名及删除后的 ID、初始重合、原输出保留和干净的 MJCF 包。
- 不依赖 URDF 或 sim.json 的独立 MJCF 加载确认默认 ctrl=0 时仍产生恒力。
- 新标签 230×270 窄侧栏底部可达；类型切换保留力值及控件，勾选保留值，保存序列化保留稳定 ID；力值有效变更触发增量预览。
- 未打开、使用或修改任何用户现有 SW 工程；真实 CAD 拾取和原生 SW 宿主界面尚未现场验证。

安装包含新增 site_forces.py。日志：build/site-force-build.log、site-force-ui.log、site-force-backend.log、site-force-setup.log。界面图：build/site-force-bottom.png。

## 使用限制

运行中应避免两点重合。恒力不等同于 connect 或弹簧。每条启用恒力新增一个 actuator 控制槽，其 ctrl 不起作用；外部控制器应按名称定位关节执行器。原有 URDF/STL、减面、缓存和导出功能保持。
